PERSONAL SCAN — Arabic prank website

Files:
- index.html: website structure
- style.css: horror / dark red design
- script.js: quiz, loading animation, and fictional result

Run locally:
Open index.html in your browser.

Publish on GitHub Pages:
1. Create a new public repository on GitHub.
2. Upload index.html, style.css, and script.js to the repository root.
3. Open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish the site and use the displayed URL.

Privacy:
This is a harmless fictional prank. It does not collect or transmit answers, does not access GPS, and does not discover real names or addresses. The result only echoes an optional name typed into the page.
